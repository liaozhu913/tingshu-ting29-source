# 听书源全站点优化核对清单

本仓库当前运行时代码主要发布在 `sources_by_ting29.jar` 中。为了避免再次出现“书名、分类、收听数”等字段错位，所有站点后续修改都按下面的统一准则核对。

## 统一字段规则

- 书名必须来自标题链接或详情页标题，不能来自整行文本拼接结果。
- 分类必须来自当前分类入口或明确标注“分类/类型”的字段，不能从播放量、收听数、人气字段推断。
- 收听数、播放数、人气、点击数只能作为元信息展示，不能写入书名或分类。
- 详情页 URL 和章节 URL 必须规范化为绝对地址。
- 搜索页和分类页应共享同一个 item 字段映射函数，避免两个入口展示不一致。

## 已核对站点

| 站点 | 重点风险 | 优化策略 |
| --- | --- | --- |
| 29听书网 | 移动分类接口返回字段可能为空 | 保留接口字段优先，空字段再用 HTML fallback。 |
| 恋听网 | 列表标题与播放状态靠近 | 标题只取标题链接文本，播放状态写入 meta。 |
| 乐听网 | 搜索和分类模板可能不同 | 搜索/分类共用清洗后的 item 映射。 |
| 麒麟听书 | JSON/HTML 混用 | JSON 字段优先，HTML 仅做兜底。 |
| 275听书 | 移动详情和播放页路径不同 | URL 统一绝对化，播放地址单独校验。 |
| 有听网 | API 音频字段变化 | 保留 `api-getneoplay` 链路，并检查空音频兜底。 |
| 听13网 | 通用 PTCMS span 下标会混淆书名、分类、收听数 | 使用站点专用 `Ting13Parsing`，标题、分类、统计分离。 |
| 爱听书 | 章节目录页可能分页 | 优先移动目录页抓取全量章节，章节 URL 去重。 |

## 发布前检查

运行：

```bash
python3 tools/audit_jar_strings.py
```

该脚本会从 `sources_by_ting29.jar` 的 `classes.dex` 提取可读字符串，确认所有已注册站点仍有对应二进制痕迹，避免发布时漏打包某个站点。
